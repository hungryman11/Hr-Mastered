  - **Current:** `https://*.onrender.com`

## RECOMMENDATIONS FOR DEPLOYMENT

### Step 1: Update render.yaml with production secrets

```yaml
envVars:
  # ... existing vars ...
  - key: ZOHO_CLIENT_ID
    value: "<from Zoho API Console>"
  - key: ZOHO_CLIENT_SECRET
    value: "<from Zoho API Console>"
  - key: ZOHO_REFRESH_TOKEN
    value: "<from Zoho token exchange>"
  - key: ZOHO_ORG_ID
    value: "<from Zoho account>"
  - key: ZOHO_USE_MOCK
    value: "False"
  - key: ZOHO_OAUTH_REDIRECT_URI
    value: "https://<production-url>.onrender.com/app/callback"
  - key: ZOHO_ALLOWED_REDIRECT_URIS
    value: "https://<production-url>.onrender.com/app/callback"
  - key: EMAIL_HOST_USER
    value: "<zoho-email>"
  - key: EMAIL_HOST_PASSWORD
    value: "<zoho-app-password>"
  - key: DEFAULT_FROM_EMAIL
    value: "<noreply@company.com>"
```

### Step 2: Fix LeaveBalance.year hardcoding

File: `core/models/leave.py`
```python
from django.utils import timezone

class LeaveBalance(CompanyScopedModel):
    # ...
    year = models.PositiveSmallIntegerField(default=lambda: timezone.now().year)
```

### Step 3: Register production callback URL in Zoho API Console

1. Go to Zoho API Console
2. Select HR Mastered application
3. Add Redirect URI: `https://<production-url>.onrender.com/app/callback`
4. Ensure scopes include `AaaServer.profile.READ`

### Step 4: Generate Zoho refresh token (if needed)

If ZOHO_REFRESH_TOKEN is not available:
1. Use the `get_refresh_token.py` script to manually generate
2. Store securely in Render environment

### Step 5: Create production employee seed/import

Before GO-LIVE, provision employees via:
- `python manage.py import_infinity_staff <employees.xlsx>` (if file exists)
- Or custom import script
- Ensure no test employees remain

### Step 6: Run production checks

```bash
# In production environment
python manage.py check
python manage.py check --deploy
python manage.py migrate --check
python manage.py shell
# > from django.conf import settings
# > print(settings.DEBUG)  # Should be False

```
